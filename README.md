# Chat-Application-with-OOP
Fuzetek-Internship Mini project
1.1 Purpose
This document outlines the requirements for a simple chat application that allows
users to send and receive messages, while administrators (admins) have
additional privileges such as deleting messages and managing users.
1.2 Scope
- Users can send and receive messages.
- Admins have additonal privileges, such as deleting messages and removing
users.
- The system has centralized user management via the ChatApp class.
